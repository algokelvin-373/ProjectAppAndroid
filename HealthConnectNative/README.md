# HealthConnectNative

Sample/demo integrating Android Health Connect APIs natively.

## Tech Stack
- Kotlin
- Android Views (XML)
- Health Connect API

## Project Structure
- `app/` - Main module

## How to Run
1. Open in Android Studio
2. Sync Gradle
3. Ensure Health Connect is available on target device/emulator (Android 11+ recommended)
4. Grant required permissions when prompted

## Notes
Minimal example for reading/writing or exploring Health Connect data flows.
