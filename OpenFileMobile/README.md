# OpenFileMobile

App demonstrating opening files from device storage on mobile.

## Tech Stack
- Kotlin
- Android Views (XML)
- File Access / Storage

## Project Structure
- `app/` - Main module

## How to Run
1. Open in Android Studio
2. Sync Gradle
3. Run on device/emulator
4. Test file open/pick actions (handle permissions as needed)

## Notes
Covers file intent handling & runtime permissions for storage access.
