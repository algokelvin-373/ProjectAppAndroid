# VideoProcessing

Sample project for basic video processing/editing on Android.

## Tech Stack
- Kotlin
- Android Views (XML)
- Media / Video Processing

## Project Structure
- `app/` - Main module

## How to Run
1. Open in Android Studio
2. Sync Gradle
3. Run on device (recommended for media operations)
4. Select/process video as per app flow

## Notes
Explores Android media APIs for video manipulation/processing.
