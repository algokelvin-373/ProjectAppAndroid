# Deeplinks

Simple app to demonstrate Android Deep Links (implicit/explicit intents & handling incoming links).

## Tech Stack
- Kotlin
- Android View System (XML)
- Deep Links / Intent Filters

## Project Structure
- `app/` - Main module
- `build.gradle` / `build.gradle.kts` - Project & module config

## How to Run
1. Open in Android Studio
2. Sync Gradle
3. Run on emulator/device (API >= minimum SDK)
4. Test deep link via `adb am` or intent from browser/other app

## Notes
Learning/demo project for handling and testing Android Deep Links.
