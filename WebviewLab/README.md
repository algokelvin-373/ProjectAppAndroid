# WebviewLab

Lab/playground for Android WebView experiments.

## Tech Stack
- Kotlin
- Android Views (XML)
- WebView

## Project Structure
- `app/` - Main module

## How to Run
1. Open in Android Studio
2. Sync Gradle
3. Run on emulator/device
4. Load URL or local HTML inside WebView

## Notes
Covers WebView settings, JS bridge basics, navigation, and security considerations.
